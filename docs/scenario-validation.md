# 地形与设施遮挡原生场景验证

2026-10-29，在 Factorio **2.1.23 / Space Age / mac-arm64** 中对模组 **1.10.8 + 当前工作区改动** 执行。测试从固定存档复制出隔离目录，使用独立本地服务器；不覆盖源存档，并在退出后核对源文件 SHA-256。

## 场景矩阵

`tests/native/scenario-matrix.lua` 覆盖 90 个场景。使用不规则矿区、大矿机紧凑布局、四路均分输出；部分场景先应用矿区，再单独设置输出。绕行、预览、应用及撤销都调用实际规划器与原生游戏接口。

| 分类 | 数量 | 验证内容 |
| --- | ---: | --- |
| 水、深水、岩浆、高温岩浆、四种油海、两种氨海、碎冰海面 | 33 | 每种地块分别检查绕行、允许填充的出口、禁止填充的受阻出口 |
| 填充与强制应用组合 | 6 | 水、岩浆、深油海分别执行普通强制与 Ctrl 强制 |
| 科技尚未解锁 | 4 | 填土、岩浆地基、油海地基、人工冰层仍能预览、应用及撤销 |
| 地形开关独立性 | 4 | 开启其他地形填充不能解除当前地形的限制 |
| 矿区内已有设施与自然障碍 | 12 | 矿机、插件塔、传送带、树木、岩石、悬崖分别保留或清除 |
| 输出位置已有建筑 | 8 | 完整布局与仅输出两条路径，各测普通、强制、Ctrl 强制及设施清障 |
| 输出自然障碍与清障独立性 | 6 | 树木／岩石保留、原生强制拆除、仅开启设施清障时仍保留自然障碍 |
| 不可填充区域 | 2 | 地图边界、太空空地，即使开启其他地形填充也拒绝普通放置 |
| 油海上的装货站 | 2 | 开启填油海可放置；关闭时拒绝受阻的固定站体 |
| 原有拆除标记 | 1 | 撤销不能取消用户原先已有的拆除标记 |
| 其他朝向 | 9 | 北、南、西分别检查油海填充、油海绕行和 Ctrl 强制拆除 |
| 混合地形 | 3 | 水／岩浆／油海全部填充、仅填水时拒绝受阻均分器、仅填水并绕开其余地形 |

每个场景检查预览不会创建虚影或下达拆除命令；成功应用后检查填充虚影、输出端点和拆除标记。应用后的撤销必须由实际 GUI 事件处理器完成，再检查虚影清空、原有实体保留及拆除标记恢复。

## 结果与行为边界

- **90/90 通过**。58 个场景首次预览可应用；32 个首次预览按预期受阻，其中 9 个继续通过显式强制操作应用，23 个保持拒绝普通放置。拒绝受阻目标是预期结果，不表示测试失败。
- 普通强制应用遵循原生 Shift 规则：可标记树木、岩石等自然障碍，已有建筑会保留，因此布局可能只放置一部分。Ctrl 强制或设施清障会标记冲突建筑拆除。
- 岩浆和四种油海均正确使用原生 `foundation`；冰星两种氨海及碎冰海面使用 `ice-platform`，由“填补水域”开关控制；普通水域使用其原生覆盖地块。覆盖类型从当前地块原型读取。
- 装货站跨深油海的场景生成并放置 **108 个地基虚影**。混合地形只填水的绕行场景生成 **28 个填充虚影**，不填岩浆或油海。
- 固定均分器有完整占地：即使点击的出口格位于允许填充的水面，只要相邻分流器压住禁止填充的岩浆／油海，普通应用仍应拒绝。移动输出或明确开启对应填充后再应用。
- 同时重跑原有 `placement` 套件，原生蓝图属性、地下带出入口、电杆铜线、岩浆岸线插件塔、装货站位置、各清障点击方式及撤销均通过；建设机器人能实际拆除已有设施并回收箱内物品。

另用 `--suite terrain-warnings` 检查实际游戏 GUI：未解锁时显示警示但控件仍可勾选；科研完成后原控件即时清除警示，科技撤回后恢复；切换冰星会提示人工冰层；切换阵营及进入油田模式保持正确提示和原勾选状态。回收配方默认可用不代表制作科技已解锁，不能借此隐藏警示。

这些测试覆盖原版地块及设备的隔离场景，不等价于遍历第三方模组的全部碰撞规则。场景中的游戏 tick 用于记录测试进程，不作为性能基准。

## 复现

```sh
python3 scripts/test-placement.py \
  --factorio /path/to/factorio --data /path/to/game-data \
  --save /path/to/fixture.zip --suite scenario-matrix \
  --output /path/to/results --timeout 180

python3 scripts/test-placement.py \
  --factorio /path/to/factorio --data /path/to/game-data \
  --save /path/to/fixture.zip --suite placement \
  --output /path/to/results
```

另可使用同样参数，将 `--suite` 设为 `terrain-warnings`，运行填补选项科研警示测试。

每次执行创建独立 `placement-*` 子目录。`placement/server.log` 包含逐场景结果；`placement/data/script-output/scenario-matrix.json` 保存场景 ID、预览状态、实体／填充数量、拆除状态及通过标志。`placement/manifest.json` 保存源存档哈希和被测模组包哈希。
