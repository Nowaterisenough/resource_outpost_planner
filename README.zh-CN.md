# 资源开采规划器

[English](README.md) | [简体中文](README.zh-CN.md)

**Resource Outpost Planner** 是 Factorio 的矿区与油田规划工具：先框选资源，查看机器人不会施工的地面预览，调整配置，确认后再应用建设蓝图。

## 主要功能

- 矿机和抽油机在窗口顶部直接点图标选择，共用一套配置界面。
- 品质使用各设备和插件下方的紧凑图标按钮选择，黄色表示当前品质；仅列出已解锁品质，传送带、普通管道、地下管道和热管不显示品质选择。设备与插件的左右两列统一对齐，去掉分组内重复的设备小标题。窗口顶部只保留标题，撤销放在底部操作区。
- 启用《太空时代》后可使用大矿机；选中不适合当前布局的设备时，会自动切换到兼容布局。
- 地面预览随配置更新，不提前生成建设蓝图、填土或下达拆除命令。
- 采矿支持传送带、地下传送带、电杆、灯光、插件塔、插件、流体输入和蓝图模板。
- 油田支持抽油机方向、管网、电杆、插件塔、寒冷星球供热和实体品质。
- 地形处理统一为两项：悬崖在“避／拆”之间切换，水、岩浆、雷池在“避／补”之间切换；矿机、插件塔、油田和传送带连接遵循同一选择。
- 填补按地形使用填土、地基或平台；不可填补的地形仍需避让。保留已有设施单独设置，不影响拆悬崖或补地形。
- 取消只移除当前预览；撤销会移除最近应用的建设蓝图，并取消其新增的拆除命令，前提是相关实体仍存在。
- 重新选区会清掉旧预览、统计叠层及本规划器上次生成且尚未施工的建设规划，包含连接出口和填补规划；已建成设备和其他建设规划保留。Shift 选区仍用于追加当前预览的资源。

## 游戏版本与安装

需要 **Factorio 2.1**。《太空时代》为可选内容；大矿机、额外资源和寒冷星球功能需要对应的游戏内容。

将 `resource-outpost-planner_1.9.4.zip` 放入 Factorio 的 mods 目录；也可将仓库放进名为 `resource-outpost-planner` 的文件夹。启用模组并重启游戏。

本独立发行版使用内部标识 `resource-outpost-planner`。启用前请停用原版 Mining Patch Planner，或此前沿用其内部标识的安装包。存档中已有建筑会保留；原规划器的数据和未应用预览不会自动导入，切换后请重新配置规划器。

## 操作流程

1. 按 **Ctrl+M**，或点击蓝图样式的快捷按钮，打开规划器。
2. 点击 **选区** 后拖动框选资源；使用 **Shift + 鼠标左键拖动** 添加另一片范围。再次点击选区或按 **Q** 退出框选，保留预览。
3. 查看地面预览，实体使用蓝图原始贴图及绿色／红色放置提示。机器人不会施工这些预览。
4. 选择设备并调整配置，预览会自动重新计算。
5. 点击 **应用**，重新检查选区并生成建设蓝图。允许的填土及拆除只在这一步开始。
6. 点击 **取消预览** 丢弃草稿，不影响之前已经应用的布局。

矿石或流体资源会自动选择对应模式。“采矿布局”只控制矿区布局。电杆不适用于当前采矿布局时，本次采矿会使用该布局的默认电杆并提示；油田仍使用共用配置中选定的电杆。

两套界面按开采设备、输送连接、供电供热、插件塔、布局选项、地形处理排列。矿机和抽油机的插件紧挨 **开采设备**，塔内插件紧挨 **插件塔**。选入插件即启用，右键清除后关闭；没有插件槽的设备会隐藏插件设置。电杆、插件塔及油田可选设备不再提供独立的“无”按钮：点击设备启用，再次点击已选设备或右键点击关闭，黄色选中状态表示已启用。矿机、传送带等必需设备仍保持一个有效选择。

面板底部的 **选区** 按钮与独立 **输出** 区域控制光标模式，黄色表示当前模式。打开面板时不启用工具；预览重算也不会自动切换光标。生成带传送带的矿区预览后，点击 **输出** 才会拿起原生蓝图光标，按当前输出带数显示多条传送带，并使用所选传送带类型和品质。点击地图设置或移动出口；**R / Shift+R** 旋转蓝图。再次点击输出或按 **Q** 退出，保留出口和方向；再次进入、连续点击及带数、类型或品质变化后都保持方向。连接传送带显示在地面预览中，应用后与矿区一起施工，撤销也包含连接。应用或取消预览会退出工具模式。最近一次应用的矿区也可点击输出继续连接。油田和没有传送带出口的布局禁用输出按钮。

输出区域的 **均分输出** 默认关闭，路数默认 **8**，适合 4 节货厢双面上货。开启后可输入 1 至 32 路，再用 **输出** 选择位置；光标按均分后的路数显示传送带。均分器采用 Raynquist/Dogmai 的成熟蓝图，按来带数、输出路数和地下带长度匹配布局，保留分流器优先级与地下带配对。没有直接对应的规格时，在标准均分蓝图上添加并带或回流连接。均分的是整条传送带，不会增加总产量。需要为均分器留出空间，受阻部分会标红并禁用应用；应用、撤销、重选清理均包含均分器。关闭后恢复原有出带方式。油田及物流箱布局不显示此选项。

输出区域的 **生成装货站** 会在主均分器后添加火车装货站。默认 **2 车头、4 货厢、双边装货**；可设置 1 至 8 个车头、1 至 16 节货厢，单边每节货厢一路，双边每节货厢两路，均分路数自动计算。均分器按实际输入、输出路数匹配 1–8 路矩阵蓝图，3 进 8 出使用对应的 3 进 8 出蓝图。超出矩阵且没有直接模板的双边装货规格可组合小矩阵与二分支，例如 3 进 10 出使用 3 进 5 出再各分两路。均分器靠近第一节货厢，允许车头和站台伸出输送区域；末级分流器直接供给缓存箱机械臂，缩短两侧支路。每侧包含六个缓存箱、集装机械臂和电杆，并生成铁路、车站、进出站信号灯及配置的火车。点击 **输出** 拿起完整原生蓝图；**R / Shift+R** 旋转，**H / V** 翻转。点击地图设置地面预览，应用后才放置建设规划，撤销包含装货站。矿区已经应用时，输出会单独进入预览并保留矿区规划。施工后连接两端铁路和电网，为车头加燃料并设置列车时刻表。

**统计** 统一控制放置报告和传送带负载显示。应用后在聊天栏打印矿机数量、内部传送带行数、资源格数及遗漏提示；打开 **ALT 模式**，预览和已应用布局都会显示每侧传送带的预计产量和容量占用率，用于判断传送带能否运走矿机产出。100% 表示满载，超过 100% 标红；大矿机按已研究的传送带堆叠容量计算。两侧分别计算瓶颈，总览显示可输送产量、实际出口带数和瓶颈损失。产量估算读取资源采矿时间、物品产出、原生插件品质效果、插件槽数及采矿产能研究，并与传送带合并判断共用容量规则。关闭统计会同时停止报告和负载显示。旧设置中任一开关开启时，合并后的统计保持开启。此选项仅控制信息显示，不改变布局。

**多放矿机** 会更积极地在矿区边缘和稀疏位置放置矿机，允许开采范围有更多重叠。这样可以增加同时开采的矿机数量，也会增加设备和传送带用量。

在采矿设置中选择 **插件塔** 可自动放置插件塔；默认关闭。启用后采用 **矿机两侧整排**：先预留连续的插件塔排，再在两排之间安排矿机列，相邻矿机列共享中间一排。塔排沿矿机列全长连续铺设，传送带使用地下段穿过塔排，电杆和灯放在运输、供电通道中。需要流体输入时，矿机与塔排之间预留管道通道。旧存档的密度选项统一使用整排布局。

**塔内插件** 独立于矿机插件，可分别选择插件塔和插件的品质。遵循“地形与设施”的避让、拆除和填补选择；塔排受阻时保留该位置的红色实体预览，提示调整范围或避障设置。普通电力矿机无法开采 3×3 插件塔正下方的中心矿格，预览会逐格标红这些够不到的矿石；大型矿机的开采范围适合连续塔排。未选择电杆时需要自行供电。预览显示插件塔数量、矿机覆盖数和每台矿机实际受到几座塔影响；传送带负载按实际覆盖、品质和衰减计算。应用后生成带插件请求的建设蓝图，撤销包含插件塔及供电电杆；蓝图模板继续使用模板自带的插件塔。

## 避障

在 **地形与设施** 中，悬崖在“避／拆”之间切换，水、岩浆、雷池在“避／补”之间切换；**保留** 控制已有设施、树木和岩石。三个选择分别生效。矿机排除受阻占地，普通传送带可以绕行，油田管网也会排除受阻位置。部分无法安全放置的辅助实体会被跳过。关键连接无法安全绕过时，“应用”保持禁用，但地面预览会保留：可用设备及已连通的带显示绿色，受阻设备和未能连通的带显示红色，并在问题位置显示调整提示。红色连接仅用于说明失败，不会施工；完全无法放置矿机时，会标红所选资源的位置。移动出口、旋转方向或修改配置后，预览会重新计算。

传送带出口连接优先使用长直线、较少转角和整齐的平行走廊；反向出口会调整带的排列顺序，避免彼此交叉。出口绕回矿区另一侧时使用嵌套的平行回绕走廊；规划顺序封住后续路线时，会尝试反向顺序。连接遵循 **地形与设施** 中的选择，同时绕开规划中的设备并保持各条传送带独立。出口被阻挡或连接不可达时，请移动目标或调整选项；应用前会再次完整验证路线。

预览使用蓝图原始贴图、尺寸、偏移和放置颜色，包括传送带转弯、地下带出入口与管道连接，不再叠加占地网格框。无法提取原始图像的设备会以图标显示。这些预览是视觉辅助，不是游戏实体。

## 油田规划

每次规划只选择一种流体资源，避免连接不同流体的管网。抽取设备需要一个流体输出容器和一个输出连接。油田支持插件塔覆盖门槛、寒冷星球供热和实体品质。抽油机和插件塔可分别选择插件及品质，应用后生成装满相应槽位的插件请求；关闭插件塔会隐藏塔内插件和覆盖门槛。可选的 **Module Inserter Extended** 集成会在应用后为油田实体插入配置好的插件。

## 开发与验证

执行 `python scripts/check-locales.py` 可检查中英文键名、引用和占位符。`scripts/render-settings-icons.py` 可从本机 Factorio 图像重建设置图标，需要 Pillow。

使用 Lua 5.2 执行 `lua tests/belt-planner.lua` 可检查传送带方向与多出口连接、转角数量、平行和回绕走廊、路线稳定性、避障、预览选点、光标方向保留、失败预览与标记清理、应用前验证、填土和撤销收集。传送带预览、失败诊断红绿图层、恢复后的标记清理、悬崖阻挡、旋转、应用位置一致性及撤销已在 Factorio 2.1.21 验证。

执行 `lua tests/preview-renderer.lua` 可检查蓝图贴图、原始尺寸、放置颜色、传送带转角、地下带出入口与管道连接。八种传送带转角也已在 Factorio 2.1.21 中与实际放置的传送带逐一核对。

执行 `lua tests/throughput.lua` 可检查采矿产量、插件品质、资源产出、堆叠容量、四种布局的并带判断、各侧饱和度和实际出口带数。

执行 `lua tests/output-balancer.lua` 可从实际生成的实体连接验证均分比例、地下带配对、回流、不同来带数及 1 至 32 路输出。

执行 `lua tests/train-station.lua` 可检查 256 组编组及单／双边配置、六箱装货连接、供电范围、地下带配对和车站旋转翻转。

执行 `lua tests/obstacles.lua` 可检查地形筛选、碰撞空间索引和放置形状缓存。[输出性能测试报告](docs/output-performance.md)包含独立游戏进程中的测试方法及优化前后数据。

执行 `lua tests/beacons.lua` 可检查插件塔开关、允许的插件、品质、效果衰减、插件请求、矿机覆盖差异及并带后的负载。`lua tests/beacon-rows.lua` 检查两侧整排、共享塔排、连续性、旋转后不重叠、管道预留通道、矿石覆盖、旧密度选项迁移和受阻红色诊断。

已在 Factorio 2.1.21 验证：预览不触发机器人施工、配置实时更新、采矿预览与落地位置一致、大矿机、油田连接、填土、避障、取消、撤销，以及预览保存读档后继续应用。
